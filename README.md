# Time-Based Fitness

A minimal fitness routine app built around **when you do things**, rather than a traditional timeline or dashboard.

## The Idea

Instead of asking the user to constantly plan their fitness routine, the app organizes guidance around the natural time periods of their day.

During onboarding, the user tells the app when they normally:

- Wake up
- Eat meals
- Work out
- Sleep
- Do other relevant activities

The app then presents the appropriate routine when the user opens it during that period.

### Example

**Morning**
→ Morning routine / breakfast guidance

**Lunch**
→ Meal guidance

**Workout**
→ Today's training session  
→ Exercises  
→ Sets/reps  
→ Form instructions

**Evening**
→ Recovery / evening routine

The goal is:

> **Open → Follow → Done.**

## Core Philosophy

- Minimal interface
- Almost zero planning by the user
- Time-period-first UX
- Clear actionable instructions
- Consistency over complexity
- AI should be optional, not required

## AI Layer

AI can be added as an optional feature rather than being required for the core product.

Possible uses:

- Adapt a workout when circumstances change
- Suggest alternatives when equipment isn't available
- Answer questions about the routine
- Adjust scheduling
- Personalize recommendations within safe boundaries

The core experience should remain useful without AI.
